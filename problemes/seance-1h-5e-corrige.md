## Nombres relatifs

::: solution Exercice 1 — Additionner et soustraire
a) $(-7)+(-5) = -12$ — même signe : on additionne, on garde le signe.

b) $(-7)+12 = +5$ — signes contraires : $12-7 = 5$, signe du plus éloigné de zéro.

c) $3-(-8) = 3+8 = +11$ — soustraire, c'est ajouter l'opposé.

d) $(-4)-(+9) = -4-9 = -13$
:::

::: solution Exercice 2 — Ranger
$-8 < -3 < -1{,}5 < 0 < 2$

Sur la droite graduée, $-8$ est le plus à gauche.
:::

::: solution Exercice 3 — Températures
Un écart se calcule par *arrivée moins départ* :
$$9-(-6) = 9+6 = 15$$
La température a augmenté de **15 °C**.
:::

::: solution Exercice 4 — Programme de calcul
$-4+10 = 6$, puis $6-(-3) = 6+3 = \mathbf{9}$.
:::

::: solution Exercice 5 — Enchaîner
On transforme d'abord toutes les soustractions en additions :
$$-8+3-(-5)-7 = -8+3+5-7$$
$$= -5+5-7 = 0-7 = \mathbf{-7}$$

Regrouper les positifs d'un côté ($3+5 = 8$) et les négatifs de l'autre
($-8-7 = -15$) donne le même résultat : $8-15 = -7$. ✔
:::

## Fractions

::: solution Exercice 6 — Additionner et soustraire
a) $\dfrac34+\dfrac58 = \dfrac68+\dfrac58 = \dfrac{11}{8}$

b) $\dfrac23-\dfrac16 = \dfrac46-\dfrac16 = \dfrac36 = \dfrac12$

c) $1-\dfrac25 = \dfrac55-\dfrac25 = \dfrac35$
:::

::: solution Exercice 7 — Comparer
On met au même dénominateur : $\dfrac56 = \dfrac{15}{18}$ et $\dfrac79 = \dfrac{14}{18}$.

Comme $14 < 15$, on a $\dfrac79 < \dfrac56$.
:::

::: solution Exercice 8 — Multiplier
a) $\dfrac34\times\dfrac89 = \dfrac{24}{36} = \dfrac23$

Plus rapide en simplifiant avant de multiplier : le 3 avec le 9, le 8 avec le 4.

b) $\dfrac25\times 15 = \dfrac{2\times 15}{5} = \dfrac{30}{5} = \mathbf{6}$
:::

::: solution Exercice 9 — Une part de part
Élèves faisant de l'allemand : $\dfrac23$ de $30 = 20$.

Bilangues : $\dfrac14$ de $20 = \mathbf{5}$ élèves.

*Le piège.* Prendre $\dfrac14$ de la classe entière donnerait 7,5 — un nombre
d'élèves non entier, ce qui suffit à repérer l'erreur. Une fraction porte
toujours sur ce qui précède, pas sur le total.
:::

## Calcul littéral

::: solution Exercice 10 — Calculer une expression
Pour $x = 3$ :

$A = 5\times 3-2 = 15-2 = \mathbf{13}$

$B = 3^{2}+1 = 9+1 = \mathbf{10}$
:::

::: solution Exercice 11 — Réduire
a) $3x+7x = 10x$

b) $5x+2-x+6 = 4x+8$ — on regroupe les $x$ entre eux, les nombres entre eux.

c) $4\times 3x = 12x$
:::

::: solution Exercice 12 — Distribuer
a) $3(x+4) = 3x+12$

b) $5(2x-3) = 10x-15$

Le facteur touche **chaque** terme de la parenthèse : $3x+4$ serait une
distribution à moitié faite.
:::

::: solution Exercice 13 — Tester une égalité
Pour $x = 4$ : à gauche $4\times 4-1 = 15$, à droite $2\times 4+7 = 15$.
Les deux membres sont égaux : l'égalité est **vraie**. ✔

Pour $x = 3$ : à gauche $11$, à droite $13$. L'égalité est **fausse**.

Une égalité littérale n'est ni vraie ni fausse en soi : elle l'est pour
certaines valeurs, et c'est ce qu'on appellera résoudre une équation.
:::

::: solution Exercice 14 — Traduire un programme
L'expression est $3x+5$.

Pour $x = -2$ : $3\times(-2)+5 = -6+5 = \mathbf{-1}$.
:::

## Proportionnalité et statistiques

::: solution Exercice 15 — Vitesse moyenne
$2$ h $30$ min $= 2{,}5$ h — et non $2{,}30$ h.
$$v = \frac{180}{2{,}5} = 72$$
La vitesse moyenne est de **72 km/h**.
:::

::: solution Exercice 16 — Pourcentage d'une population
$$35\,\% \text{ de } 640 = \frac{35}{100}\times 640 = 0{,}35\times 640 = 224$$

**224 élèves font de l'espagnol.**

*Contrôle :* 35 % est un peu plus du tiers, et le tiers de 640 vaut environ 213.
:::

::: solution Exercice 17 — Effectifs et fréquences
a) Effectif total : $12+9+4+5 = \mathbf{30}$ élèves.

b) Fréquence du judo : $\dfrac{4}{30} \approx 0{,}133$, soit environ
$\mathbf{13{,}3\,\%}$.

Une fréquence se calcule toujours **sur le total**, jamais sur une autre
catégorie.
:::

::: solution Exercice 18 — La moyenne
$$\frac{12+15+8+14+11}{5} = \frac{60}{5} = 12$$
**La moyenne de Lina est de 12.**
:::

## Géométrie

::: solution Exercice 19 — Angles et parallèles
L'angle **alterne-interne** mesure aussi $\mathbf{62°}$ : si deux droites
parallèles sont coupées par une sécante, alors les angles alternes-internes
sont de même mesure.

L'angle **adjacent** forme avec lui un angle plat, donc il mesure
$180-62 = \mathbf{118°}$.

!fig \droitesparalleles{62°}
:::

::: solution Exercice 20 — Somme des angles
a) $180-(47+68) = 180-115 = \mathbf{65°}$.

b) Les deux angles à la base sont égaux : $180-40 = 140$, puis $140\div 2 = \mathbf{70°}$ chacun.
:::

::: solution Exercice 21 — Symétrie centrale
L'image d'un segment par une symétrie centrale est un **segment de même
longueur**, et il lui est **parallèle**.

Sont conservés : les longueurs, les mesures d'angles, les aires, l'alignement.

La différence avec la symétrie axiale : la symétrie centrale **ne retourne
pas** la figure — c'est un demi-tour. Un texte reste lisible à l'envers, alors
qu'il devient un texte en miroir par symétrie axiale.
:::

::: solution Exercice 22 — Parallélogramme
Dans un parallélogramme, les angles opposés sont égaux et deux angles
consécutifs sont supplémentaires.

$\widehat{C} = \widehat{A} = \mathbf{115°}$

$\widehat{B} = \widehat{D} = 180-115 = \mathbf{65°}$

Contrôle : $115+65+115+65 = 360°$, la somme des angles d'un quadrilatère. ✔
:::

## Grandeurs et volumes

::: solution Exercice 23 — Volumes
a) Pavé droit : $8\times 5\times 3 = \mathbf{120}$ **cm³**.

b) Cylindre : $V = \pi R^2 h = 3{,}14\times 3^2\times 10 = 3{,}14\times 90 = \mathbf{282{,}6}$ **cm³**.
:::

::: solution Exercice 24 — Convertir
a) $1$ dm³ $= \mathbf{1\,000}$ cm³ \qquad b) $2\,500$ mL $= \mathbf{2{,}5}$ L

c) $1$ L $= \mathbf{1\,000}$ cm³

Un volume se convertit **trois fois** : $1$ dm $= 10$ cm, donc
$1$ dm³ $= 10\times 10\times 10$ cm³. Et la passerelle à retenir est
$1$ L $= 1$ dm³.
:::

::: solution Exercice 25 — L'aquarium
**Volume total.** $60\times 30\times 40 = 72\,000$ cm³.

**En litres.** $1$ L $= 1\,000$ cm³, donc l'aquarium contient 72 L une fois plein.

**Aux trois quarts.** $72\times\dfrac34 = 54$.

**L'aquarium contient alors 54 litres d'eau.**

*Contrôle :* trois quarts, c'est un peu plus de la moitié de 72, donc un
résultat autour de 54 est cohérent. ✔
:::
