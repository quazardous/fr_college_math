Voici le nombre de livres empruntés par neuf lecteurs en un mois :
2 ; 5 ; 1 ; 8 ; 3 ; 12 ; 4 ; 3 ; 7.

a) Calcule la moyenne.

b) Détermine la médiane.

c) Calcule l'étendue.

::: solution
a) $\dfrac{2+5+1+8+3+12+4+3+7}{9} = \dfrac{45}{9} = 5$ livres.

b) On range : 1 ; 2 ; 3 ; 3 ; 4 ; 5 ; 7 ; 8 ; 12.
Neuf valeurs, la médiane est la **cinquième** : **4**.

c) $12-1 = 11$.

*Remarque.* La moyenne (5) dépasse la médiane (4) : le lecteur à 12 emprunts
tire la moyenne vers le haut.
:::
