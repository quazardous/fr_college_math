## Relatifs et priorités

::: solution Exercice 1 — Multiplier et diviser
a) $(-7)\times(-5) = +35$ — deux signes identiques, résultat positif.

b) $(-8)\times 3 = -24$

c) $\dfrac{-42}{-6} = +7$

d) $\dfrac{54}{-9} = -6$
:::

::: solution Exercice 2 — Enchaîner
a) $-3+4\times(-5) = -3+(-20) = -23$ — la multiplication d'abord.

b) $(-2)\times 3\times(-4) = +24$ — deux facteurs négatifs, résultat positif.

c) $-5-(-3)\times 2 = -5-(-6) = -5+6 = +1$
:::

::: solution Exercice 3 — Le piège des carrés
$(-4)^{2} = (-4)\times(-4) = +16$

$-4^{2} = -(4\times 4) = -16$

Dans le premier cas, la parenthèse indique que **c'est $-4$** qui est élevé au
carré. Dans le second, seul le 4 l'est, et le signe moins reste devant.
:::

## Fractions

::: solution Exercice 4 — Multiplier
a) $\dfrac23\times\dfrac57 = \dfrac{10}{21}$

b) $\dfrac34\times\dfrac89 = \dfrac{24}{36} = \dfrac23$
(plus rapide en simplifiant avant : $3$ avec $9$, et $8$ avec $4$)

c) $\dfrac{5}{6}\times\dfrac{3}{10} = \dfrac{15}{60} = \dfrac14$
:::

::: solution Exercice 5 — Diviser
a) $\dfrac34\div\dfrac25 = \dfrac34\times\dfrac52 = \dfrac{15}{8}$

b) $\dfrac{7}{8}\div\dfrac{7}{4} = \dfrac{7}{8}\times\dfrac{4}{7} = \dfrac{4}{8} = \dfrac12$
:::

::: solution Exercice 6 — Enchaîner
La multiplication passe avant l'addition :
$$\frac12+\frac13\times\frac34 = \frac12+\frac{3}{12} = \frac12+\frac14 = \frac24+\frac14 = \frac34$$
:::

## Puissances et racine carrée

::: solution Exercice 7 — Calculer
a) $2^{5} = 32$ \qquad b) $(-3)^{3} = -27$ (exposant impair, signe conservé)

c) $10^{4} = 10\,000$ \qquad d) $5^{0} = 1$
:::

::: solution Exercice 8 — Les règles
a) $3^{4}\times 3^{2} = 3^{6}$ — même base, on **additionne** les exposants.

b) $2^{3}\times 5^{3} = (2\times 5)^{3} = 10^{3}$ — même exposant, on multiplie les bases.
:::

::: solution Exercice 9 — Grands nombres
$150\,000\,000 = 1{,}5\times 10^{8}$ km.

On déplace la virgule de 8 rangs vers la gauche, ce qui se compense par $10^{8}$.
:::

::: solution Exercice 10 — Racines carrées
a) $\sqrt{81} = 9$ car $9^{2}=81$. \qquad $\sqrt{144} = 12$ car $12^{2}=144$.

b) $7^{2}=49$ et $8^{2}=64$, et $49 < 54 < 64$, donc $7 < \sqrt{54} < 8$.
:::

## Calcul littéral et équations

::: solution Exercice 11 — Développer et réduire
a) $3(x+4) = 3x+12$

b) $5(2x-3) = 10x-15$

c) $2(x+1)+3(x-4) = 2x+2+3x-12 = 5x-10$
:::

::: solution Exercice 12 — Factoriser
a) $7x+21 = 7(x+3)$ \qquad b) $4x-12 = 4(x-3)$
:::

::: solution Exercice 13 — Résoudre
a) $5x+3 = 23$, donc $5x = 20$ et $x = 4$.
Vérification : $5\times 4+3 = 23$. ✔

b) $7x-2 = 4x+13$, donc $3x = 15$ et $x = 5$.
Vérification : $7\times 5-2 = 33$ et $4\times 5+13 = 33$. ✔
:::

::: solution Exercice 14 — Mettre en équation
Soit $x$ la largeur en cm. La longueur vaut alors $x+4$.

Périmètre : $2\times\big(x+(x+4)\big) = 36$, soit $2(2x+4) = 36$,
donc $4x+8 = 36$, puis $4x = 28$ et $x = 7$.

**La largeur est de 7 cm et la longueur de 11 cm.**

Contrôle : $(7+11)\times 2 = 36$. ✔
:::

## Pythagore et géométrie

::: solution Exercice 15 — Calculer l'hypoténuse
$ABC$ est rectangle en $A$, donc $BC$ est l'hypoténuse :
$$BC^{2} = AB^{2}+AC^{2} = 6^{2}+8^{2} = 36+64 = 100$$
$$BC = \sqrt{100} = 10 \text{ cm}$$
:::

::: solution Exercice 16 — Calculer un autre côté
$DEF$ est rectangle en $D$, donc $EF$ est l'hypoténuse. On **soustrait** :
$$DF^{2} = EF^{2}-DE^{2} = 13^{2}-5^{2} = 169-25 = 144$$
$$DF = \sqrt{144} = 12 \text{ cm}$$
:::

::: solution Exercice 17 — La réciproque
Le plus long côté est 15 cm. On calcule les deux membres **séparément** :
$$15^{2} = 225 \qquad\qquad 9^{2}+12^{2} = 81+144 = 225$$

Les deux résultats sont égaux, donc d'après la réciproque du théorème de
Pythagore, **le triangle est rectangle**, et l'angle droit est celui opposé
au côté de 15 cm.
:::

::: solution Exercice 18 — Droite des milieux
$I$ et $J$ étant les milieux de deux côtés, le théorème des milieux donne :

- $(IJ)$ est **parallèle** à $(AB)$ ;
- $IJ = \dfrac{AB}{2} = \dfrac{14}{2} = \mathbf{7}$ **cm**.
:::

::: solution Exercice 19 — Volume
Aire de la base : $6\times 6 = 36$ cm².
$$V = \frac{36\times 10}{3} = \frac{360}{3} = 120 \text{ cm}^{3}$$
Ne pas oublier le $\div 3$, propre à la pyramide et au cône.
:::

## Statistiques et proportionnalité

::: solution Exercice 20 — Médiane et étendue
On range : $8$ ; $11$ ; $12$ ; $14$ ; $15$ ; $19$ ; $22$.

Sept valeurs : la médiane est la **quatrième**, soit $\mathbf{14}$.

Étendue : $22-8 = \mathbf{14}$.

*Remarque.* Que la médiane et l'étendue soient égales ici est une coïncidence.
:::

::: solution Exercice 21 — Moyenne pondérée
$$\frac{8\times 3+12\times 5+15\times 2}{3+5+2}
= \frac{24+60+30}{10} = \frac{114}{10} = 11{,}4$$
:::

::: solution Exercice 22 — Coefficient multiplicateur
$$240\times 1{,}15\times 0{,}85 = 234{,}60$$

**Le prix final est de 234,60 €** : il n'est **pas** revenu à 240 €.

Une hausse puis une baisse du même pourcentage ne se compensent jamais, parce
que la baisse s'applique à un montant plus élevé que la hausse. Il manque 5,40 €.
:::

::: solution Exercice 23 — Partage proportionnel
Total des parts : $2+3+5 = 10$.

Valeur d'une part : $4\,200\div 10 = 420$ €.

Les trois associés reçoivent $840$ €, $1\,260$ € et $2\,100$ €.

Contrôle : $840+1\,260+2\,100 = 4\,200$. ✔
:::
